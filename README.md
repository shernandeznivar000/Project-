# Technology Quiz Game

## Project Description
The Technology Quiz Game is a simple Python program that asks the player questions about computers and technology. The player chooses an answer for each question and receives a final score.

## Purpose
I created this project to practice Python programming and make a program that people can actually interact with.

## Features
- Start a quiz from a simple menu
- 8 technology questions
- Multiple-choice answers
- Random question order
- Score calculation
- Percentage calculation
- Feedback based on the final score
- Option to play again or exit

## How to Run
1. Make sure Python is installed.
2. Open `quiz_game.py`.
3. Run the file.
4. Choose `1` to start the quiz.
5. Enter A, B, C, or D for each question.

## Python Concepts Used
- Variables
- Lists and dictionaries
- Functions
- Loops
- If/elif/else statements
- User input
- String formatting
- The `random` module
